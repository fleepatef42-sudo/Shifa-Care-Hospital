# Shifa Care Hospital

Hospital operations dashboard for managing daily healthcare workflows through a polished Arabic interface.

## Live Site

- Live: https://fleepatef42-sudo.github.io/Shifa-Care-Hospital/
- Source: https://github.com/fleepatef42-sudo/Shifa-Care-Hospital

## Features

- Sign-in flow with session persistence.
- Dashboard for patients, doctors, appointments, invoices, and inventory.
- Add-record forms for core hospital entities.
- Search, notifications, profile menu, and theme preference handling.
- RTL Arabic layout with responsive UI sections.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage and SessionStorage
- Font Awesome

## Access

Use the sign-in page to start an operations session.

## Project Note

This portfolio version focuses on the operations interface and stores session data in the browser.
