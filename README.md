# Shifa Care Hospital

Hospital operations dashboard demo for managing daily healthcare workflows through a polished Arabic interface.

## Live Demo

- Live: https://fleepatef42-sudo.github.io/Shifa-Care-Hospital/
- Source: https://github.com/fleepatef42-sudo/Shifa-Care-Hospital

## Features

- Demo sign-in flow with session persistence.
- Dashboard for patients, doctors, appointments, invoices, and inventory.
- Add-record forms for core hospital entities.
- Search, notifications, profile menu, and theme preference handling.
- RTL Arabic layout with responsive UI sections.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage and SessionStorage
- Font Awesome

## Demo Access

Use any valid-looking username or email and a password with at least 4 characters. The login is intentionally client-side for demo purposes.

## Project Note

This is a front-end portfolio demo. It does not include a real authentication server, database, or protected medical data.
